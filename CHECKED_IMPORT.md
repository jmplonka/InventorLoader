# Checked IPT and IAM import — proposed extension

This extension was verified with FreeCAD 1.1.4 and its bundled Python 3.11.

## Changes

- Imported native profiles now retain partial-line point dimensions instead of incorrectly applying them to the whole line. Projected distances between a point and an axis-aligned line use supported FreeCAD point-to-point constraints with the correct sign. Imported constraints that would displace the stored curves or make the sketch redundant/conflicting are left unbound with `InventorConstraintNotes`; the original geometry is restored before rebuilding profiles. Truly zero-length line selections between coincident source vertices are omitted. Native reconstruction stops at the first failed feature rather than producing a cascade of missing-base errors.
- Sketch annotation strings without stored glyph outlines are retained as editable source text, with an explicit unrendered-layout status. They do not become extrusion profiles. Text with recoverable saved outlines continues to use the live glyph implementation.

- Preserves the stored browser order, feature/sketch labels, origin planes, work axes and points. Source feature and sketch entries forward editing to the native operations and expose their dimensions; internal Boolean dependencies do not create additional visible nesting. Repeated names such as `Origin` remain identical in separate IAM components.

- Editable linear/circular sketch text: source font table and font runs are decoded; changing the text updates every glyph, inner wire, linked profile and cut, including changed character/hole counts. The circular source case was verified for text replacement, text size changes, restoration against STEP, and save/reopen/recompute.

- Reconstructs the two analytic helical intersection branches between a circular screw sweep and a coaxial cylinder. The stored approximation is used only to identify a unique branch within its declared tolerance. Reconstructed curves are independently checked on both analytic surfaces to 0.0000001 mm. This fixes a helical part's `BOPAlgo_InvalidCurveOnSurface` STEP-reference failure without relaxing the strict geometry checks.
- Extrusions have an Inventor-style editor with actual New body, Join/Pad, Cut/Pocket, Intersection and Surface operations. Editable options drive the live Part extrusion and Boolean result; these are imported feature controllers rather than PartDesign Pad/Pocket objects. Browser entries retain the original source names. Cutting tools and intermediate positive stages remain internal; only final bodies are displayed.
- Every native IPT/component is compared automatically to the saved BRep exported to STEP and read by `Part.read`. The `InventorStepComparison` property records solid counts and extra/missing material volumes. A mismatch aborts the import. This also applies to definitions loaded through IAM.
- Sketch redundancies introduced when attaching a sketch to its support are resolved after attachment, preventing empty cutting profiles in two flange fixtures. Final geometry must still pass the STEP comparison.
- Construction planes retain a persistent view provider so their hidden state survives saving, reopening and recomputation.
- Fix dated 2026-10-22: completes native profiles (including their sketch attachments and intermediate recomputations) before creating their extrusion object. This prevents transient `No object linked` errors while importing text-contour cuts. The live profile dependency and final solid validation are retained. Degenerate source sketch lines and changed IAM component revisions remain reported.
- Reads zlib and Zstandard Inventor streams (the `zstandard` Python package is required for newer files).
- Builds signed ACIS helices from their stored vector basis, avoiding the old quadrant/axis reflection bug.
- Reconstructs circular helical sweep surfaces from their analytic recipe rather than the coarse stored display spline. Curve and surface interpolation is checked against analytic samples to 0.0000001 mm.
- Reads the additional fields present since Inventor 2025 in assembly records `55CE9B23` and `375EAEE5` without shifting their references or transformations. Unknown optional graphics attributes are retained as opaque payloads; they are not used to reconstruct solid geometry.
- Reconstructs supported circular cone/cylinder intersection curves from their surfaces instead of exporting coarse ACIS guides. Ellipses remain analytic; hyperbolas use exact rational splines; other returned intersection splines are checked against both surfaces to 0.000001 mm. Ambiguous branches retain the original path and remain subject to solid validation.
- Preserves the ACIS intcurve reversal in STEP. Closed guide splines now use the correct arc, avoiding self-intersections around toroidal fillets.
- Translates saved BRep to OpenCascade, converts closed shells to solids, enforces a 0.0001 mm tolerance budget, and performs a Boolean geometry check on each solid. Excessive tolerances and open/invalid solids are rejected.
- Registers IAM in FreeCAD's Open/Import dialog. Loads external components as reusable definitions and placed App::Link occurrences, including nested IAMs. Resolves renamed files by stored identity/revision and original filenames. Searches OldVersions for the exact saved revision before accepting a changed current revision. Ambiguous or missing references produce an explicit error.
- Uses private temporary parser directories instead of creating or clearing dump directories beside the original documents.
- Imports transactionally, so a failure does not leave a partial assembly in an existing document.

## Native mode and limitations

Native mode reconstructs stored sketches, parameter spreadsheets, selected sketch regions, extrusion join/cut/intersection operations, constant-radius fillets, supported chamfers, circular-profile coils and supported projected contours. Profiles and Boolean operations retain dependencies and recompute. The stored Inventor browser drives the visible feature/sketch hierarchy and labels. Profiles, positive cutting tools and previous Boolean operands remain internal calculation objects, without extra tree levels. Component occurrences expose the original source children directly, without definition/history folders. Component shapes contain final solids only, regardless of hidden work planes and intermediate features. Each component has its own parameter namespace. The native choice propagates through IAM component definitions and nested assemblies.

Fillets expose named radius properties linked to the source parameter spreadsheet. Chamfers expose distance/angle properties and a flip control; equal-distance, two-distance and distance/angle definitions drive the native edge list through expressions. Change dimensions in the component's parameter spreadsheet (or deliberately remove a property's expression before overriding it). This preserves source formulas; changing the numeric edge list alone would be overwritten by its expression. Variable fillets with intermediate radius stations are rejected.

Sketches on explicitly stored work planes use FreeCAD attachments. Named planar support faces are attached when exactly one matching plane exists on the stored creating feature. Attachment offsets preserve the original sketch frame. Independent projection planes share the same support without introducing circular dependencies. Stored text outlines follow their source sketch. `InventorAttachment` records whether a sketch's support was linked or its saved position was retained. Ambiguous/unsupported supports retain their placement; no neighbouring face is guessed. Work planes without a decoded construction relation retain their saved frame and can be moved directly.

Native output must match the saved final solid by solid count and occupied volume in both directions (relative volume tolerance 0.000001). Every final solid also passes a strict OpenCascade Boolean check. Unsupported or mismatching features fail transactionally with an explicit error; native mode never substitutes the final saved body. STEP mode remains available for checked saved geometry.

Imported base features do not contain their original construction history. A complete saved historical shell can be used as that base, but missing historical boundaries are rejected. This does not invent missing sketches. General tapered coils, coil end transitions and arbitrary unsupported Inventor features are not implemented. The complete set of Inventor sketch constraints and sketch-pattern associations is not reconstructed; some retained construction geometry has fixed coordinates. Supported driving dimensions remain linked to the parameter sheet. Topological edge changes after large edits can require repairing downstream references, as in other imported feature histories.

This is a checked reconstruction of supported source features, not universal parity with Inventor's feature/constraint solver. Uniform-font sketch text with recoverable glyph frames is imported as a live text object (`String`, `FontFile`, `Size`, `Tracking`), including circular text paths. Double-click the text in the tree or edit `String`; linked profiles and material-removal extrusions rebuild. Original saved glyph outlines preserve the unedited import exactly, including across font versions. Edited strings use the installed declared font. Unsupported formatting/layouts retain the saved curve contours with an explicit warning; complete Inventor rich-text and arbitrary text paths are not implemented. Changing sketch orientation does not reconstruct every Inventor direction/axis relation.

IAM support reproduces component hierarchy and rigid placements, with editable definitions in native mode. Inventor mates/constraints, motion, alternative model states, mirrored/scaled occurrences and drawing/presentation documents are not reconstructed. The supported external occurrence records require an unambiguous file stem/name and default saved placement. Unsupported layouts fail explicitly.

An IAM refers to external files; the IAM alone is not sufficient when those files are missing. Shared template IDs alone are not considered a reliable match. Changed revisions are marked with `InventorRevisionChanged` and logged.

## Source browser presentation

Native imports retain source folders (including Origin), original feature order, and consumed sketches under their source features. Double-click a source sketch to enter the original Sketcher object. A source extrusion/fillet/chamfer entry exposes the linked native dimensions; double-click forwards to its native editor. `DimensionTable` opens the component parameter table. Text remains a child of the appropriate sketch. The actual native operations remain live, and their source results are still checked against STEP.

Double-click an imported extrusion to open its Inventor-style task panel. Operations are New body, Pad/Join, Pocket/Cut, Intersect and Surface. Extents are Distance, Two distances, Through all, To face, To next and From/to; reverse direction, symmetry, taper and extrusion direction are editable. To face/From-to currently require parallel planar boundary faces; To next requires a planar face that covers the complete profile. Unsupported inclined or curved boundaries produce an explicit error. Stored From/to and path-extent records have not yet been decoded and are rejected; From/to can be configured after import using selected planar faces. Symmetry applies to Distance and Through all. A changed numeric value preserves a simple linked spreadsheet constant; overriding a derived formula is explicit in the field tooltip. Cancel leaves the feature unchanged, and invalid edits roll back. The initial STEP validation is performed after the source tree has been built and recomputed. Original validation describes the imported state; later intentional edits change geometry. `InventorModified` on the extrusion result records changes to its extrusion settings.

IAM occurrences expose their source children directly. There are no additional `Component definitions` or `Skizzen und Konstruktionsverlauf` folders, and no repeated root-assembly wrapper under the FreeCAD document. Three origin planes, axes and the center point retain their stored frames. Source annotation, pattern and constraint browser entries whose full semantics are unsupported are retained as explicitly marked source entries, not falsely reconstructed constraints. Inventor mates/motion remain unsupported. A stale/incomplete browser cache is recorded in `InventorStructure` notes and unmapped decoded source features are retained.

Geometric subobject traversal and STEP export use final results only. Hidden calculation stages, cutting tools and datum-plane faces do not become exported solids. Source extent expressions that refer to computed native properties retain that object context when displayed on browser entries. Tests also inspect the populated FreeCAD tree after reopening, rather than relying on hierarchy metadata alone.
